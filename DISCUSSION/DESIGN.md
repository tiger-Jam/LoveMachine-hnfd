# 花札こいこい 最強AI 設計書

## 1. 目的

ユーザー提供のルールエンジン(Python)上で動作する、こいこい最強クラスのAIを作る。特に **捨て札選択**と**こいこい判断**を的確に行うことで、カジュアル〜熟練プレイヤー相手に高い勝率を出すことを目指す。

## 2. 基本方針

### 2.1 なぜ確率計算だけでは足りないか

既存研究 (Guan et al., IEEE TAI 2023) では、Transformer + モンテカルロ強化学習で熟練人間相手に勝率53%。純粋な確率計算だけでは到達不可能なレベル。

一方、本AIでは **「勝率80%を出せる人間プレイヤーの思考を構造化して再現する」** ことを目標にする。以下の階層構造に基づく。

### 2.2 ユーザーの勝ち筋(階層構造)

**階層1: 方策選択(目標の動的切り替え)**

```
if 光札が狙える:
    目標 = 光系の役(三光/雨四光/四光/五光)
elif 他の大きな役が狙える:
    目標 = その役
else:
    目標 = 最小役(カス/たん/たね)で素早く上がる
    こいこいしない
```

**階層2: 役完成可能性の評価** (確率計算で裏付ける)

「取れなさそう/揃えられそう」を定量化。不明札に必要札が何枚あるか、残りターン数で引ける確率、場にマッチがあるか、などから各役の完成確率を算出。

**階層3: 相手妨害(防御)**

相手の取り札を監視して、相手の役完成をブロック。共通原理は:

> 相手が欲しがっている札のカテゴリを特定する → そのカテゴリの札を場に出さない/手札から消す

### 2.3 多局最適化(ユーザーの直感)

**「明らかに無理な局は最小役で素早く上がって親権を保持、次局で勝負」**という戦略は、単局最適化を超えた**多局最適化**。既存AI研究にも珍しい視点。

実装では、AIが以下の状態を認識:
- 現在のラウンド番号 (1〜N)
- 総ラウンド数 (3/6/12)
- 自分の累計得点
- 相手の累計得点
- 現局の進行状況(山札・手札・場札・取り札・捨て札履歴・こいこい状態)

## 3. ルール仕様(確定分)

### 3.1 札構成

- 全48枚、12ヶ月×4枚
- **光札 5枚**: 松に鶴、桜に幕、芒に月、柳に小野道風(雨)、桐に鳳凰
- **種札 9枚**: 梅に鶯、藤に不如帰、菖蒲に八橋、牡丹に蝶、萩に猪、芒に雁、菊に盃、紅葉に鹿、柳に燕
- **短冊札 10枚**: 赤短3枚(松/梅/桜)、青短3枚(牡丹/菊/紅葉)、無地短冊4枚(藤/菖蒲/萩/柳)
- **カス札 24枚**

### 3.2 配り方

- 手札: 各プレイヤー 8枚
- 場札: 8枚(表向き)
- 山札: 残り 24枚

### 3.3 役と得点

| 役 | 条件 | 点数 |
|---|---|---|
| 五光 | 光5枚 | 15 |
| 四光 | 柳以外の光4枚 | 10 |
| 雨四光 | 柳を含む光4枚 | 8 |
| 三光 | 柳以外の光3枚 | 6 |
| 赤短 | 松・梅・桜の赤短3枚 | 6 |
| 青短 | 牡丹・菊・紅葉の青短3枚 | 6 |
| 猪鹿蝶 | 萩猪+紅葉鹿+牡丹蝶 | 5 |
| 花見で一杯 | 桜幕+菊盃 | 5 |
| 月見で一杯 | 芒月+菊盃 | 5 |
| たね | 種札5枚以上 | 1 (+1/枚) |
| たん | 短冊札5枚以上 | 1 (+1/枚) |
| カス | カス札10枚以上 | 1 (+1/枚) |

**手役(配り直し)**: 手四(同月4枚)・くっつき(同月ペア4組)ともに**採用**。6点。

### 3.4 こいこい・得点倍率

- 役成立時 → 「勝負」または「こいこい」
- **7点以上倍率は採用しない**(単純合計)
- 相手がこいこい宣言後に勝った場合 → **相手の得点2倍**
- 複数回こいこいがされた場合 → **最後にこいこいした人**が倍率なしで得点(手札切れ時)

### 3.5 流局

両プレイヤー手札切れで役なし → 引き分け、**親はそのまま続投**。

### 3.6 その他ルール

- 菊に盃 = タネのみ(化け札不採用)
- 花見で一杯・月見で一杯 = **採用**
- 場札に同月4枚出た場合 = **配り直し**
- ラウンド数 = **3 / 6 / 12 から選択**、それぞれ別AIを作る

## 5. 評価関数の設計

### 5.1 局面価値 V(state)

```
V(state) = α × E[自分の役点数]
         − β × E[相手の役点数]
         + γ × 多局価値調整
```

- `E[自分の役点数]`: 現状から最終的に自分が得る得点の期待値(全役の成立確率×点数の和)
- `E[相手の役点数]`: 同様に相手側
- `多局価値調整`: 残り局数・得点差に応じた補正

### 5.2 多局価値調整(局数別AIの核心)

**3局制**: 短期決戦。大きな役の価値を高く評価、小さい役は割引。

```
adjustment_3 = 0 (そのまま)
期待値重みは大きな役に傾斜(例: 光系×1.5、カス×0.5)
```

**12局制**: 長期戦。安定性重視、親権保持価値を評価。

```
adjustment_12 = +α_親 × P(親権保持)
              + β_安定 × P(負けない)
小さい役での上がりを奨励
```

**6局制**: 序盤(1-3局)は安定、終盤(4-6局)は得点差に応じて切り替え。

### 5.3 こいこい判断

こいこいの期待値:

```
EV(こいこい) = P(役追加成功) × 追加期待点
             − P(相手に上がられる) × (現役点数 + 相手役期待点) × 2
             ※ 2倍は相手が倍率を得るため

EV(勝負) = 現役点数 × (1 − P(流局判定負け))
        + 親権獲得価値
```

多局設定:
- **3局制**: こいこいハードル低め(勝負を急ぐ)
- **12局制**: こいこいハードル高め(無理しない、親権を守る)

### 5.4 捨て札選択(本題)

各手札候補 c について:

```
score(c) = A × 自分役進捗への貢献
         − B × 相手への危険度
         + C × 「取れない札を早く処理する」係数
```

- **自分役進捗への貢献**: c を出した後の「目標役の完成確率の変化」
- **相手への危険度**: c を場に置いた場合、相手がそれを取って役完成に近づく確率
  - 相手の取り札から相手の目標役を推定
  - 相手の目標役に c が貢献するか、を評価
- **処理係数**: 役に寄与しない札は早めに切る方が、後半の自由度が上がる

## 6. 相手手札推定(opponent_model.py)

相手の手札は不明だが、以下から推定できる:

- 取り札から逆算: 相手がどの役を狙っているか
- 捨て札から逆算: 相手が取らなかった札 → 相手が持っていない可能性(または必要ない)
- 手番選択のパターン: こいこいする/しない判断の癖(人間相手には意味あり、AI同士は自己強化)

初期実装では「相手手札は不明札から均等分布」と仮定。後のフェーズでベイズ推定を追加。

## 8. 局数別パラメータ設計

### 8.1 調整可能パラメータ一覧

```python
@dataclass
class AIConfig:
    total_rounds: int

    # 評価関数の重み
    self_weight: float = 1.0           # 自分の得点期待値の重み
    opp_weight: float = 0.8            # 相手の得点期待値の重み
    parent_value: float = 0.0          # 親権保持の価値(円)
    lead_protection: float = 0.0       # リード時の守備係数

    # 目標役選択の閾値
    hikari_pursuit_threshold: float = 0.3   # 光系を狙う確率閾値
    fallback_to_kasu_threshold: float = 0.2 # 最小役に切り替える閾値

    # こいこい判断の閾値(役点数ごと)
    koikoi_threshold_base: float = 0.5  # 現役点数に応じて追加リスクを取る基準
    koikoi_risk_aversion: float = 1.0   # リスク回避係数

    # 捨て札選択の重み
    discard_progress_weight: float = 1.0  # 自分進捗への寄与
    discard_danger_weight: float = 1.2    # 相手危険度への重み
    discard_cleanup_weight: float = 0.3   # 処理価値の重み
```

### 8.2 3局制パラメータ

```python
config_3 = AIConfig(
    total_rounds=3,
    parent_value=0.5,            # 低め(親権の長期価値が少ない)
    hikari_pursuit_threshold=0.2, # 積極的に光系を狙う
    fallback_to_kasu_threshold=0.15,
    koikoi_threshold_base=0.4,    # こいこい積極的
    koikoi_risk_aversion=0.7,

```

```python
config_12 = AIConfig(
```
